      02 / ABOUT

      我们是谁

      NHS_board（南河三预测P）是民间 Bili_board 术力口传说曲周榜预测项目，每周产出预测视频与文字版榜单。与 Bilibili、nicovideo、Billboard JAPAN 及任何榜单运营方均无隶属或合作关系。

      收录范围

      B 站所有「非中文」音声合成音乐，引擎包括但不限于术力口，具体以实际公示为准。

      截止时间

      每周二 0:00（北京时间）数据截点，此前增量计入本期推演。

      不做什么

      不刷量、不代投、不代表官方口径；榜单仅展示自制公式下的排名，不代表成员立场。

      03 / MECHANISM

      预测怎么算

      五步流水线，从采集到复盘，每一步都尽量透明。

      01

      采集

      抓取平台公开播放、收藏、硬币、点赞等增量数据。

      02

      加权

      按时间衰减处理，剔除异常波动。

      03

      推演

      套用自制计分公式估算本周得分，排出 TOP20 候选。

      04

      发布

      周榜发布前公开预测视频与文字版。

      05

      复盘

      对照实际榜单计算命中率，修正下一周权重。

      计分公式

      S = 播放基数 + Δ收藏×15 + Δ硬币×30 + Δ点赞×3（演示自拟，非官方口径）

      05 / FAQ

      常见问题

      NHS_Board 是官方榜单吗？

      不是。我们与任何榜单运营方都没有隶属或合作关系，只是民间预测项目。

      文字版和视频版一样吗？

      同一套推演结果。文字版把 TOP20 直接列出来，方便快速看和转发；彩蛋与详细解说请看视频版。

      「预测」和「实际榜单」差多少？

      每期复盘会公开命中率与偏差曲，预测是推演不是定论。

      能不能帮我把某首曲子「做」上榜？

      不能也不做。我们不刷量、不代投，只做公开数据的可复现推演。

      想提名曲目、加入创作组？

      私信 プロキオンNHS_预测P，或到最新一期视频评论区留言。
